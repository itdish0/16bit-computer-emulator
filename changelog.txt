#%% V1.4 (02/25/26)
# Added JR and JP commands
# Updated DJNZ to be relative
# Updated Compiler to turn absolute locations into relative offset for JR and DJNZ; throws error if too far.
# JR -1 and DJNZ -1 do nothing, lest they be capable of soft-locking the computer
# JR +1 and DJNZ +1 also do nothing, as it's the same effect as if they didn't trigger.
# JR +0 and DJNZ +0 cause a NOP instruction, as they jump to the 0x00 byte.
# For relative jumps, bytes are treated as signed (-128 to 127) so that backwards jumps are possible.
# Important note: jumps are relative FROM THE BYTE WITH THE JUMP DISTANCE; i.e. the 0x05 in JR 0x05.
# So 0x7005010203040506070809 will jump to the byte marked 05;
#   From ^^   to   ^^
# This is partly to balance the fact that the max backwards jump (-128) is larger than the max forwards jump (127)

#| LD (0xF000) a    // Set to 0xF000 initially to avoid unexpected crashes.
#| INC a
#| LD c a
#| DJNZ loop
